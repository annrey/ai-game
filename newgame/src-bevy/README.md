# OpenClaw Bevy 混合架构前端

## 概述

这是 OpenClaw 游戏项目的 Bevy 游戏引擎前端实现，采用混合架构设计：

- **保留文字冒险核心玩法**：AI 驱动的叙事体验不变
- **增强视觉表现**：使用 Bevy 的 2D 渲染能力提供动态背景、天气效果、粒子系统
- **统一技术栈**：全部使用 Rust，与现有后端完美集成

## 核心功能

### 1. 视觉增强系统 (visuals/)

- **动态背景**：根据场景类型（森林、城镇、地牢等）自动切换背景色
- **天气效果**：支持晴、雨、雪、雾、暴风雨等天气的视觉效果
- **时间覆盖**：根据游戏内时间（黎明、正午、黄昏、午夜）调整画面色调
- **粒子系统**：雨雪粒子动画效果

### 2. UI 系统 (ui/)

使用 egui 实现的原生 Rust UI：

- **左侧边栏**：导航菜单、委员会成员状态
- **右侧面板**：世界状态、角色状态、物品栏、任务日志
- **中央区域**：叙事文本显示（支持滚动）
- **底部面板**：选择按钮区域

### 3. 游戏状态 (game_state.rs)

完整的数据结构支持：

- 叙事历史和当前文本
- 玩家选择系统
- 角色属性（生命、魔力、体力）
- 游戏时间和天气
- 库存和任务系统
- 设置选项

### 4. 引擎桥接 (engine_bridge.rs)

- 使用 tokio Runtime 在 Bevy 的同步环境中调用异步游戏引擎
- 状态转换：将游戏核心的 WorldState 转换为 Bevy 前端的 GameState
- 提供保存/加载游戏功能

## 与现有代码集成

### 工作区配置

在 `newgame/Cargo.toml` 中添加：

```toml
[workspace]
members = [
    "crates/core",
    "crates/memory",
    "crates/world",
    "src-tauri",
    "src-bevy",  # 新增
]
```

### 依赖关系

```toml
[dependencies]
bevy = "0.15"
bevy_egui = "0.31"
game_core = { path = "../crates/core" }
world = { path = "../crates/world" }
memory = { path = "../crates/memory" }
```

## 技术特点

1. **纯 Rust 实现**：从前端到后端统一使用 Rust，无 JavaScript/TypeScript
2. **跨平台**：Bevy 支持 Windows、macOS、Linux
3. **高性能**：相比 Web 前端，Bevy 提供原生性能
4. **可扩展**：ECS 架构便于添加新功能
5. **热重载**：开发时支持资源热重载

## 与 Tauri 版本的对比

| 特性 | Tauri 版本 | Bevy 版本 |
|------|-----------|----------|
| 技术栈 | Rust + Web 前端 | 纯 Rust |
| 渲染方式 | WebView | 原生 GPU |
| UI 框架 | HTML/CSS/JS | egui + Bevy UI |
| 性能 | 中等 | 高 |
| 包大小 | 较大（含 WebView）| 较小 |
| 视觉能力 | 受限于 Web | 完整的 2D/3D |
| 开发复杂度 | 较低 | 较高 |
