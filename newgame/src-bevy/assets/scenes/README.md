# 场景背景图资源

本目录存放游戏场景的背景图片资源。

## 文件名规范

| 文件名 | 场景类型 | 描述 |
|--------|----------|------|
| `forest.png` | Forest | 森林场景 |
| `town.png` | Town | 城镇场景 |
| `dungeon.png` | Dungeon | 地牢场景 |
| `beach.png` | Beach | 海滩场景 |
| `mountain.png` | Mountain | 山地场景 |
| `custom.png` | Custom | 自定义场景 |

## 图片规格

- **分辨率**: 1920x1080 或 1280x720
- **格式**: PNG (支持透明通道)
- **色彩模式**: RGBA

## Alpha 渐变效果

图片底部 30% 区域应包含 alpha 渐变，从底部向上逐渐变透明，用于与游戏 UI 融合。

## 获取资源

可以使用以下 AI 图像生成工具创建场景：
- Midjourney
- Stable Diffusion
- DALL-E
